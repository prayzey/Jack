Bundled font files for Gilt live in this folder.

Included families:
- Atkinson Hyperlegible
- Instrument Sans
- JetBrains Mono

License copies are stored in `Sources/Gilt/Resources/Fonts/Licenses/`.

Why this folder exists:
- keep the app's font options predictable across Macs
- avoid relying on whatever fonts a user happens to have installed
- make direct-download builds self-contained
